# 仕様書: 並び替え機能 (Node Order)

このドキュメントは、タスク（ノード）の表示順序を制御する機能の仕様を定義します。

## 1. 概要
ユーザーはタスクの優先順位や実行順に並び替えを行うことができます。並び替えは「兄弟ノード（同じ親を持つノード）」の間でのみ発生し、階層構造（親子関係）は維持されます。

## 2. データモデル
- **`order` プロパティ**: 各ノードは数値を持ち、この値が小さい順に上から描画されます。
- **`children` 配列**: 親ノードが持つ子ノードのID配列。この配列の要素の並び順は、常に `order` プロパティの昇順と一致（同期）していなければなりません。
  - **重要**: 配列の順序と `order` プロパティの不整合を防ぐため、並び替え発生時は両方を同時に更新します。

## 3. UI/UX と操作方法

### 3.1 インスペクターの移動ボタン
- 選択中のタスクのインスペクター内「並び替え」セクションにある「↑」「↓」ボタンで操作します。
- **挙動**:
  - 1つ上または下の兄弟ノードと `order` プロパティを入れ替えます。
  - 同時に、親ノードの `children` 配列内の順序もソートして更新します。
  - これにより、ツリー表示（react-arborist）およびインスペクターの「How」リストが即座に再描画されます。

### 3.2 ドラッグ＆ドロップ (ListView)
- 画面左側のツリー（react-arborist）でドラッグ＆ドロップを行うことで、直感的に順序や親子関係を変更できます。
- **挙動**:
  - ドロップされた位置（インデックス）に基づき、親ノードの `children` 配列を更新します。
  - 新しい並び順に従って、兄弟ノード全員の `order` プロパティを `0, 1, 2...` と再割り当てします。

## 4. 制約事項と境界条件
- **最上部/最下部**: すでに兄弟の中で一番上または一番下にいる場合、ボタンを押しても位置は変わりません。
- **重複の解決**: データに `order` の重複や欠落がある場合、並び替え操作の瞬間に自動的に `0` からの連番にリペア（再割り当て）されます。
