# インスペクター直下兄弟要素 並び替えDnD 仕様書

## 1. 誰の、どんな困りごとを解決するのか

- **対象者**: インスペクターを日常的に使うユーザー。
- **困りごと**: セクションの表示順が固定されており、使っていくうちに「Why? をもっと上に見たい」「AI機能はあまり使わないから下にしたい」という個人の最適順序が変わっても変更できない。
- **解決策**: inspector-header 右端のトグルボタンで「並び替えモード」に入り、ドラッグハンドルで各セクションを自由に並び替えられるようにする。順序は localStorage に保存し、次回起動後も維持される。

## 2. ユーザーの操作フロー

> **★ 実装者への強調事項**
> 並び替え中もセクション内のインタラクション（テキストエリア入力、アコーディオン開閉等）を壊してはならない。
> ハンドル部分をドラッグした場合のみ並び替えが発動し、セクション内のクリックは通常通り動作すること。

### ステップ① — 並び替えモードに入る
```
inspector-header の右端にある「並び替え」ボタン（GripVertical アイコン）をクリック
  ↓
各セクションの左端にドラッグハンドル（⠿）が出現
ボタンがハイライト状態（active 色）になる
```

### ステップ② — ドラッグで順序を変更する
```
ハンドルをつかんで上下にドラッグ
  ↓
セクションがリアルタイムに移動（他のセクションはアニメーションで押し上げ/押し下げ）
  ↓
ドロップすると新しい位置に確定・localStorage に保存
```

### ステップ③ — 並び替えモードを終了する
```
inspector-header の「並び替え」ボタンを再度クリック
  ↓
ハンドルが消えて通常表示に戻る
変更した順序はそのまま維持
```

### 並び替え対象セクション（6つ）

| キー | セクション | デフォルト順 |
|-----|-----------|------------|
| `description` | 説明・メモ | 1 |
| `ai` | AI機能（AIInsights） | 2 |
| `schedule` | スケジュール・フェーズ | 3 |
| `dependency` | 依存関係 | 4 |
| `why` | Why? | 5 |
| `how` | How? | 6 |

### 固定（並び替え対象外）
- `inspector-header`（タイトル・進捗バー）→ 常に先頭
- MECEウォーニングカード → 条件付き表示のため順序固定（How? の直前に常時表示）

## 3. 境界条件

| ケース | 挙動 |
|--------|------|
| 並び替えモード中にノードを切り替えた場合 | 並び替えモードはそのまま維持（Inspector はアンマウントされないため） |
| 初回起動時（localStorageにデータなし） | デフォルト順で表示 |
| セクション順序はグローバル | ノードを変えても同じ順序が適用される |

## 4. 変更スコープ

### やること
- `@dnd-kit/core` + `@dnd-kit/sortable` をインストール
- `inspector-header` 右端に並び替えトグルボタン（GripVertical アイコン）を追加
- 並び替えモード時に各セクション左端にドラッグハンドルを表示
- セクション順序を `localStorage`（キー: `logido_section_order`）に永続化
- ドラッグ中のセクションに視覚的なフィードバック（半透明 + 影）

### やらないこと
- セクションの表示/非表示設定
- ノードごとに異なるセクション順序
- キーボードによる並び替え
