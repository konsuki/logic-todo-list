# 仕様書: リスト表示切替時のフェーズフィルター保持

## 1. 概要
リスト表示（ListView）において、選択されたフェーズフィルターの状態を保持し、ビューを切り替えても元の状態が復元されるようにします。

### 解決する課題
ユーザーがリスト表示で特定のフェーズ（例：「実行期」）に絞り込んで作業している際、ツリー表示に移動して全体像を確認し、再びリスト表示に戻ると、フィルターが「すべて」にリセットされてしまいます。これにより、再度フィルターを選択し直す手間が発生し、作業効率が低下する問題を解決します。

## 2. データモデル
フィルター状態はブラウザの `localStorage` に保存します。

- **キー名**: `logido_list_phase_filter`
- **データ形式**: 文字列（'ALL', '構想期', '設計期', '実行期' など）

## 3. UI/UX 仕様
1. **保存のタイミング**:
   - フェーズフィルターが変更された時。
2. **復元のタイミング**:
   - リストビューがマウントされた時。
3. **初期状態**:
   - `localStorage` にデータがない場合、または無効な値の場合は `'ALL'`（すべて）とします。

## 4. 制約事項・考慮事項
- 有効なフェーズ名は、アプリケーションで定義されているものに準拠します。
