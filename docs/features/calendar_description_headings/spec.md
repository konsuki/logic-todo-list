# カレンダー書き込みのメモ内容（見出し付き＋実行手順）仕様書

## 1. 誰の、どんな困りごとを解決するのか

- **誰のため**: カレンダーを見返すユーザー本人（および、実施記録を第三者に見せる場面）。
- **困りごと**: 現状、タスク完了時にカレンダーへ書き込むイベントの説明（description）に、どの情報が「説明とメモ」「詳細意図」なのか区別できる見出しがなく分かりづらい。また「実行手順」が書き込まれていない。
- **本タスクの価値**: 見出しを付けて各情報を区別し、実行手順も含めることで、実施内容を一目で分かる形でカレンダーに残す。

## 2. データの流れ

タスク完了（`toggleStatus` で DONE）時に、`useTodoTree.js` の `handleToggleStatus` 内でイベントの description を組み立てる。現在は `[intent, description]` を単純連結している。

### 変更後の description フォーマット

```
## 説明とメモ
{node.description}

## 詳細意図
{node.intent}

## 実行手順
{node.procedure}
```

- 各項目の間は見やすさのため **1行空ける**（空行を挟む）。
- **空の項目でも見出しは必ず出す**（内容が空でも「## 説明とメモ」等の見出しは表示する）。

## 3. 境界条件・例外ケース

- 3項目すべて空の場合 → 3つの見出しだけが並ぶ（空の description にはしない）。
- 一部だけ空の場合 → 空の項目も見出しだけ表示。
- 改行を含む内容 → そのまま保持（見出しの直後に内容、次の見出しとの間は1行空ける）。

## 4. 優先順位

| 優先度 | 項目 | 扱い |
|--------|------|------|
| 必須 | 見出し付きフォーマット（3項目） | 実装 |
| 必須 | 実行手順（procedure）を含める | 実装 |
| 必須 | 空でも見出しを出す | 実装 |
| 必須 | 項目間を1行空ける | 実装 |

## 5. スコープ外

- 見出しの文言変更（`## 説明とメモ` 等の文言は今回固定。変更したい場合は別タスク）。
- リッチテキスト化（マークダウン見出しをプレーンテキストとして description に入れるだけ）。
