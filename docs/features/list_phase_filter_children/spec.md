# 仕様書: フェーズフィルター時の子タスク表示

## 1. 概要
リスト表示（ListView）において、フェーズフィルターで絞り込んだ際、合致したタスクだけでなく、その配下にあるすべてのタスク（子孫ノード）も表示されるようにします。

### 解決する課題
ユーザーが特定のフェーズ（例：「実行期」）に絞り込んで作業する際、該当タスクの配下にある具体的なToDo（子タスク）が隠れてしまうため、タスクの分解内容を確認しながら作業することができず、集中して作業できない問題を解決します。

## 2. フィルタリング仕様
- **基本ルール**: `ListView` の `useMemo` 内にある `checkVisibility` 関数を修正します。
- **表示条件**:
  1. ノードの `phase` が選択された `phaseFilter` と一致する場合、そのノードを表示する。
  2. あるノードが表示対象となった場合、その**すべての子孫ノード（children）も強制的に表示対象**とする。
  3. 表示対象となったノードの**すべての祖先ノード（parents）も、ツリー構造を維持するために表示対象**とする。

## 3. UI/UX 仕様
- フィルターに合致したタスクを展開すると、その子タスクが（フェーズが異なっていても）すべて表示されます。
- これにより、ユーザーは目的のタスクに集中しつつ、その詳細なステップを追うことができます。
