# 仕様書: 旧AI機能（タスク分解・ロジックテスト）の削除

## 1. 概要
アプリケーションから、以前の「タスク分解」機能および「ロジックテスト」機能を削除し、「演繹的タスク分解」機能のみを残します。これにより、UIをシンプルにし、ユーザーの混乱を防ぎます。

### 解決する課題
新しい「演繹的タスク分解」機能が導入されたため、以前の機能は不要となりました。これらが残っていると、ユーザーがどの機能を使えばいいのか迷う原因となるため、削除して整理します。

## 2. 削除対象
### 2.1 UI コンポーネント (`AIInsights.jsx`)
- 「タスク分解」ボタンおよびそのハンドラー（`handleRequestBreakdown`）。
- 「ロジックテスト」ボタンおよびそのハンドラー（`handleRequestAudit`）。
- 提案されたタスクのリスト表示（`suggestions` 関連）。
- ロジックテスト結果の表示（`audit` 関連）。
- 関連する状態（`suggestions`, `selectedSuggestions`, `audit`）。

### 2.2 カスタムフック (`useAI.js`)
- `getBreakdownSuggestions` 関数。
- `getLogicAudit` 関数。

## 3. 維持する機能
- **演繹的タスク分解**（`getDeductiveBreakdown`）機能。
- ローディング表示やエラー表示の仕組み。
