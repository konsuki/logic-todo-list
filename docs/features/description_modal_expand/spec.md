# テキストエリア モーダル拡張入力 仕様書

## 1. 誰の、どんな困りごとを解決するのか
- **対象者**: 説明・メモに長文を書きたいユーザー。
- **困りごと**: インスペクター内のテキストエリアはパネル幅に収まる小さいサイズのため、本格的な長文入力がしづらい。
- **解決策**: 「拡大」ボタンで大きなモーダルを開き、広々とした入力欄で快適に書けるようにする。短い入力は従来通りインライン入力のまま使えるため、操作フローが増えることはない。

## 2. ユーザーの操作フロー

> **★ 実装者への強調事項**
> モーダルの内容とインスペクターの小さいテキストエリアの内容は常に一致している必要がある。
> 「モーダルを閉じたら入力内容が消える」「手動で保存しないと反映されない」という体験は絶対に起きてはならない。
> リアルタイム同期（onChange のたびに updateNode）でこれを保証する。

### 通常の短い入力（従来通り）
```
テキストエリアをクリック → 直接入力 → フォーカスを外す → 自動保存
```
モーダルは使わない。既存の onBlur 保存ロジックをそのまま維持。

### モーダルで本格入力する場合
```
① テキストエリア右上の「拡大」ボタン（Maximize2 アイコン）をクリック
        ↓
② モーダルが開く（画面全体を覆うオーバーレイ。左のリスト・ツリー表示も暗い背景で隠され、他のタスクのクリックや表示切替はできない。入力に専念できる状態）
   → モーダル内テキストエリアには「現時点の説明欄の内容」がすでに入っている
        ↓
③ モーダル内で自由に長文を入力・編集する
   → onChange のたびに updateNode が呼ばれ、インスペクターの小さいテキストエリアにも即反映される
        ↓
④ モーダルを閉じる（× ボタン or 背景クリック）
        ↓
⑤ 小さいテキストエリアにはモーダルで入力した内容がそのまま表示されている（保存済み）
```

## 3. 境界条件

| ケース | 挙動 |
|--------|------|
| モーダルを開いて何も入力せず閉じる | 元の内容が維持される（変化なし） |
| モーダルで内容を全削除してから閉じる | 空文字で updateNode が呼ばれ、説明が空になる |
| モーダル内で入力中に背景クリックで閉じる | リアルタイム反映済みのため内容は保持される |
| ノードを切り替えた時にモーダルが開いていた場合 | selectedNodeId 変化を useEffect で検知してモーダルを閉じる |

## 4. 変更スコープ

### やること
- `Inspector.jsx` に `isDescModalOpen` state を追加
- テキストエリアの右上に「拡大」ボタン（`Maximize2` アイコン）を追加
- `DescriptionModal.jsx` / `DescriptionModal.css` を新規作成（framer-motion、`ReactDOM.createPortal` で `document.body` に直接レンダリングして画面全体を覆う）
- モーダル内テキストエリアは `value`（制御コンポーネント）で Inspector の state と双方向同期
- `onChange` のたびに `updateNode` を呼んでリアルタイム保存

### やらないこと
- 既存の小さいテキストエリアの `onBlur` 保存ロジックへの変更
- モーダルへの保存ボタンの追加（リアルタイム保存のため不要）
- モーダルへの文字数カウンターや書式ボタン等の追加機能
