# 仕様書: リスト表示切替時の開閉状態保持

## 1. 概要
リスト表示（ListView）において、ノード（タスク）の展開・折りたたみ状態を保持し、ビューを切り替えても元の状態が復元されるようにします。

### 解決する課題
ユーザーがリスト表示でタスクを追加・編集している際、ツリー表示に移動して全体像を確認し、再びリスト表示に戻ると、元々閉じていたタスクまで全て展開されてしまいます。これにより視覚的なノイズが発生し、作業の継続性が損なわれる問題を解決します。

## 2. データモデル
開閉状態はブラウザの `localStorage` に保存します。

- **キー名**: `logido_list_open_state`
- **データ形式**: JSON文字列化されたオブジェクト（OpenMap）
  - 例: `{"node_id_1": true, "node_id_2": false}`
  - `react-arborist` の `initialOpenState` が受け付ける形式に合わせます。

## 3. UI/UX 仕様
1. **保存のタイミング**:
   - リストビューでノードが展開または折りたたまれた時（`onToggle` イベント）。
2. **復元のタイミング**:
   - リストビューがマウントされた時。
3. **初期状態**:
   - `localStorage` にデータがない場合は、すべてのノードを展開した状態（`openByDefault={true}`）とします。

## 4. 制約事項・考慮事項
- **タスクの削除**: 削除されたタスクのIDが `localStorage` に残る可能性がありますが、`react-arborist` は存在しないIDを無視するため、ゴミデータのクリーンアップは明示的には行いません。
- **新規タスク**: 新規追加されたタスクは `localStorage` に記録がないため、デフォルトの「開いた状態」になります。
