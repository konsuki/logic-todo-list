# 実装プラン: リスト表示切替時の開閉状態保持

このプランは、リストビューにおけるノードの開閉状態を保持・復元するためのものです。

## 大まかな手順

1. **ListView内での開閉イベントの捕捉と保存ロジックの実装**
   - `ListView` コンポーネント内に、開閉状態を追跡するための `openState`（オブジェクト）を管理する。
   - `Tree` コンポーネントに `onToggle` プロップを追加し、トグルされたノードのIDを受け取る。
   - `onToggle` ハンドラー内で、そのIDの開閉状態を反転させ、`localStorage` に `logido_list_open_state` として保存する。
   - ※ `openByDefault={true}` が設定されているため、明示的に閉じられたノードのみ `false` として記録する方針、またはトグルされた状態をそのまま記録する方針とする（詳細は実装時に確定）。

2. **ListViewマウント時の開閉状態の復元ロジックの実装**
   - `ListView` のマウント時（または `useState` の初期値）で、`localStorage.getItem('logido_list_open_state')` を取得する。
   - 取得したJSON文字列をオブジェクト（OpenMap）にパースする。パースに失敗した場合やデータがない場合は空オブジェクト `{}` とする。
   - パースしたオブジェクトを `Tree` コンポーネントの `initialOpenState` プロップに渡す。
   - ※ `react-arborist` は `initialOpenState` を初回レンダリング時のみ参照するため、これで初期状態が復元される。

3. **動作確認**
   - リストビューでいくつかのノードを意図的に閉じる。
   - ツリー表示に切り替えて全体像を確認する。
   - 再びリストビューに戻り、閉じたノードが閉じられたままである（全て展開されていない）ことを確認する。
   - ブラウザのデベロッパーツール（Applicationタブ等）で、`localStorage` の `logido_list_open_state` に正しいデータが保存されているか確認する。
