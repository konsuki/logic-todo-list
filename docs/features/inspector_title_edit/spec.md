# 仕様書：インスペクターからのタイトル編集機能の追加 (inspector_title_edit)

## 1. 背景と目的
現在、タスクのタイトルを編集するには、ツリービューで該当ノードをダブルクリックするか、リストビューでタイトルをクリックする必要があります。
しかし、インスペクター（詳細パネル）を開いてタスク内容（説明や進捗、期日）を編集している際、コンテキストの移動なしにインスペクターからタイトルを直接編集したいという要望がありました。

本機能では、インスペクターのヘッダー部分に配置されているタイトル（`<h2>`）をクリックすることで、インラインでタイトルが編集できる機能を提供します。

## 2. 変更内容とUI/UX設計

### 2.1 タイトル表示・編集ステートの追加 (`Inspector.jsx`)
- 編集状態を制御するフラグ `isEditingTitle` (boolean) と、編集用の一時タイトル `editTitle` (string) のステートを追加します。
- `selectedNodeId` や `node.title` が変化した際に、これらのステートをリセット・同期するための `useEffect` を導入します。

### 2.2 JSXの変更 (`Inspector.jsx`)
- インスペクターヘッダー内のタイトル部分を以下のように切り替えます。
  - **通常モード (`!isEditingTitle`)**:
    - `<h2>` タグでノードのタイトルを表示。
    - クラス名 `inspector-title` を付与し、ホバー時に下部へ点線を表示して「編集可能」であることをアピール（カーソルも `pointer` に変更）。
    - ツールチップ (`title`) に「クリックして編集」を表示（多言語化）。
    - クリック時に `isEditingTitle = true` へ切り替え。
  - **編集モード (`isEditingTitle`)**:
    - `<input>` 要素を表示。
    - クラス名 `inspector-title-input` を付与。
    - フォーカスを自動で当て (`autoFocus`)、`value` に `editTitle` を設定。
    - キー操作イベントハンドラを設定：
      - `Enter`: 編集を確定し保存。
      - `Escape`: 編集をキャンセルして元のタイトルに戻る。
    - `onBlur`: フォーカスが外れた際に、自動的に編集を確定し保存。

### 2.3 スタイリングの追加 (`Inspector.css`)
- `inspector-title` のホバー時の点線スタイリング。
- `inspector-title-input` が `<h2>` の外観とほぼ一致するようにフォントサイズ、マージン、文字色を最適化。
- インプット要素のボーダーやフォーカス時のアクセントカラーを設定。

## 3. 多言語化対応
`src/locales/ja.json` および `src/locales/en.json` に、ツールチップ用の翻訳キーを追加します。
- `inspector.click_to_edit`
  - 日本語: "クリックして編集"
  - 英語: "Click to edit"

## 4. 境界条件・検証ケース
- **ケース A: 空タイトル入力**:
  - タイトル入力フィールドを空にして `Enter` または `onBlur` を行った場合、保存を行わず元のタイトルに戻す（またはトリムして空文字の場合は無視）。
- **ケース B: キャンセル操作**:
  - `Escape` キーが押された場合、一切の変更を適用せず編集モードを終了する。
- **ケース C: ノード切り替え**:
  - 編集モードのまま別のノードを選択した際、編集ステートが自動的に `false` にリセットされ、新ノードのタイトルがロードされる。
