# 演繹的タスク分解（Deductive Breakdown）機能 実装プラン

## 1. 大まかな手順
1. AIプロンプト用の文脈収集処理の実装（選択ノードからルートまでの経路取得）
2. 演繹的ワークフロー（`/resolve`）を適用した新しいシステムプロンプト・API呼び出し関数の実装
3. AI応答（JSON）を再帰的にパースし、ツリーに一括追加するロジックの実装
4. `AIInsights.jsx` へのボタンUI追加と、アクションの結合

---

## 2. 手順の詳細化

### 2-1. AIプロンプト用の文脈収集処理の実装
- `src/hooks/useAI.js` に新しい関数 `getDeductiveBreakdown` を作成する。
- 引数として `node`（現在選択中のノード）と `nodes`（全ノードの辞書）を受け取る。
- `node.parentId` を再帰的に辿り、ルート（最終ゴール）から現在選択中のノードに至るまでのツリー構造の経路（パス）をテキスト化して取得するロジックを実装する。

### 2-2. 演繹的ワークフローを適用した新しいシステムプロンプトの実装
- `getDeductiveBreakdown` 内で、ユーザーから指定された `/resolve` ワークフローのルール（「目標 Q」「真なる規則前提」「検証プロトコル」等）を完全に反映したシステムプロンプトを作成する。
- APIに対して、以下の形式のような再帰的な JSON 構造で回答を返すように厳格に指示する。
  ```json
  {
    "tasks": [
      {
        "title": "タスク名（15文字以内）",
        "description": "具体的な手順や検証すべき事項",
        "children": [ /* さらに下位のタスクがあれば同様のオブジェクトをネスト */ ]
      }
    ]
  }
  ```
- 階層が深くなりすぎるのを防ぐため、プロンプト内で「最大3階層まで」などの制限を設ける。
- `sendChatMessage` を用いてAPIを呼び出し、結果をJSONとしてパースする（パース失敗時のエラーハンドリングも含める）。

### 2-3. AI応答（JSON）のパースとツリーへの再帰的追加ロジックの実装
- `AIInsights.jsx` 側で JSON を受け取り、再帰的にノードを追加する関数 `addNodesRecursively` を実装する。
- 選択中ノードのIDを親とし、受け取った配列を順に処理。ツリー構造の仕様（ノードタイプなど）に従って追加を行う。

### 2-4. `AIInsights.jsx` へのUI組み込み
- インスペクターパネル内に「演繹的タスク分解 (Deductive Breakdown)」ボタンを追加する。
- ボタン押下時にローディング状態を表示し、`getDeductiveBreakdown` を呼び出し、結果得られたJSONを元にツリーへノードを展開する処理を紐付ける。
