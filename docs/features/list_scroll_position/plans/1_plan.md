# 実装手順書: リスト表示切替時のスクロール位置保持 (1/1)

この手順書は、リスト表示のスクロール位置を `localStorage` を用いて保持・復元する実装のステップを定義します。

## 大まかな手順

1. **ListView内でのスクロール位置の監視と保存ロジックの実装**
   - `ListView.jsx` の `useEffect` 内で、`containerRef.current` からスクロール可能な内部要素を取得する。
   - スクロールイベントを監視し、`scrollTop` の値を `localStorage` に `logido_list_scroll_top` として保存する。
   - パフォーマンスのため、スクロール停止時（デバウンス）またはアンマウント時に保存を実行する。
2. **ListViewマウント時のスクロール位置の復元ロジックの実装**
   - `ListView.jsx` のマウント時（`useEffect`）に `localStorage` から保存された `scrollTop` を取得する。
   - `requestAnimationFrame` または `setTimeout` を用いて、`react-arborist` のDOMが生成された後にスクロール位置を適用する。
   - スクロール位置の適用先は、特定した内部要素の `scrollTop` プロパティとする。
3. **エッジケース（DOM未生成、高さ不足）の対応と調整**
   - 対象のDOM要素が存在しない場合は、エラーにならないようオプショナルチェイニング等で保護する。
   - 保存されたスクロール位置が現在の最大値を超えている場合は、ブラウザの自動クランプに任せる。
   - `react-arborist` の初期描画が遅れる場合に備え、復元処理を確実に実行するための工夫（例：マウント後少し待つ、または要素が見つかるまでリトライ）を検討する。
