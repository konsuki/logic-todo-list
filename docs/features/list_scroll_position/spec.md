# 仕様書: リスト表示切替時のスクロール位置保持 (List Scroll Position Retention)

このドキュメントは、リスト表示と他の表示（ツリー表示等）を切り替えた際に、リスト表示のスクロール位置を維持する機能の仕様を定義します。

## 1. 概要
ユーザーがリスト表示（ListView）で作業中に他の表示に切り替え、再度リスト表示に戻ってきた際、直前まで見ていたスクロール位置を自動的に復元します。これにより、作業コンテキストの維持と探索コストの削減を実現します。

## 2. 画面およびデータの流れ

### 2.1 スクロール位置の保存
- **対象要素**: `#root > div > main > div > div.list-view-content > div > div` (react-arboristの内部スクロールコンテナ)
- **トリガー**: 
  - `ListView` コンポーネントのアンマウント時
  - または、スクロールイベントの発生時に適宜（debounceを推奨）
- **保存場所**: `localStorage`
  - キー名: `logido_list_scroll_top`
  - 保存データ: 数値（`scrollTop` の値）

### 2.2 スクロール位置の復元
- **トリガー**: `ListView` コンポーネントのマウント時
- **処理フロー**:
  1. `localStorage` から `logido_list_scroll_top` の値を取得。
  2. `react-arborist` のツリーが描画され、対象のDOM要素が生成されるのを待つ。
  3. 対象要素の `scrollTop` に取得した値をセットする。

## 3. 境界条件と例外処理
- **リストの高さが減少した場合**: 
  - 削除などによりリスト全体の高さが減り、保存された `scrollTop` が現在の最大スクロール量を超えている場合は、ブラウザのデフォルト挙動（またはクランプ処理）により、現在の最大値（最下部）で止まるようにします。
- **DOM生成の遅延**:
  - `react-arborist` の初期描画完了を確実にするため、`useEffect` や `requestAnimationFrame` 等を用いて、要素が存在することを確認してからスクロールを実行します。

## 4. 優先順位
- **Must**: 表示切り替え時にスクロール位置が復元されること。
- **Should**: リロードしても位置が維持されること（`localStorage` 利用により達成）。
- **May**: スムーズスクロール（アニメーション）での復元。まずは瞬時の復元（実用性重視）から実装します。
