# New Task 追加時の編集 UX 改善（全選択・Escキャンセル） 仕様書

## 概要
リスト表示で親タスクを選択して Tab キー（子追加）や Enter キー（兄弟追加）を押すと、新タスク "New Task" が自動的に編集モードになるが、"New Task" の文字列が残っていてカーソルが最後尾にあるため、新タスク名を入力するには一旦全部消す必要があり、ストレスになっている問題を解決する。追加直後に "New Task" を全選択し、そのまま文字入力で置換できるようにする。あわせて Esc キーでのキャンセルを可能にする。

---

## 背景・目的

**誰の、どんな困りごとを解決するか:**
- リスト表示でショートカット（Tab: 子追加 / Enter: 兄弟追加）を使ってタスクを量産したいユーザーが、追加直後に "New Task" の文字列が残っていてカーソルが最後尾にあるため、新タスク名を入力するには "New Task" を一旦全部消す必要があり、複数連続で追加する際にストレスを感じる問題を解決する。
- 一方で "New Task" という文字列自体は、追加されたタスクであることを示すため（また量産後に個別編集するため）残したい。

---

## 用語・操作の定義

| 操作 | タイミング | 動作 |
| --- | --- | --- |
| **Tab** | タスク選択中 | 子タスク "New Task" を追加 → **編集モード＋"New Task" 全選択** |
| **Enter** | 編集中 | **確定のみ**（タイトル更新して編集終了。兄弟追加はしない） |
| **Esc** | 編集中 | **キャンセル**（編集終了、タイトルは "New Task" のまま維持、**選択は解除しない**） |
| **Enter** | 編集外・タスク選択中 | 兄弟追加（通常のショートカット動作。追加した "New Task" を全選択＋編集モード） |

---

## 期待されるフロー

```
親タスク選択 → Tab → 子 "New Task" 追加・全選択
→ そのまま文字入力で置換（または何もせず）
→ Esc → 編集を抜ける（"New Task" のまま、選択維持）
→ Enter → 兄弟 "New Task" を追加・全選択
→ Esc → Enter → を繰り返して量産
→ 後から各 "New Task" を個別クリックして編集
```

---

## 修正方針

対象は `src/components/features/list/ListView.jsx` の `ArboristNode`（リスト表示のみ）。

1. **追加直後の自動編集時に全選択**:
   - 追加直後の自動編集（`editingNodeId === data.id` で編集モードに入る）の場合のみ、input を `select()` で全選択する。
   - 通常クリック編集（`node-title` の `onClick`）では全選択しない（従来どおり）。
2. **Escape キーでキャンセル**:
   - `handleTitleSubmit` に `Escape` 処理を追加し、編集を終了してタイトルを "New Task"（変更前の値）のまま維持する。選択は解除しない。
3. **空文字ガード**:
   - 空文字のまま Enter / blur しても、タイトルを "New Task" のまま維持する（削除しない）。

---

## 境界条件・非対応ケース

| ケース | 扱い |
| --- | --- |
| Tab で子追加直後 | "New Task" を**全選択**して編集モード（文字入力で置換） |
| Enter で兄弟追加直後 | 兄弟 "New Task" を追加し**全選択**状態 |
| Esc キー（編集中） | 編集をキャンセルし "New Task" のまま残す（選択維持） |
| 空文字のまま Enter / blur | タイトルを "New Task" のまま維持（削除しない） |
| 通常クリック編集 | 従来どおり全選択しない |
| "New Task" の文字列 | **残す**（追加されたことを示すため、量産後に個別編集できるように） |
| TreeView | 本スコープ外（まずリスト表示に限定） |
| 未使用の `TodoItem.jsx` | 対象外 |

---

## 制約・注意事項
- 前回修正（`shortcut_add_auto_edit`）で追加した自動編集 `useEffect` と確定時 `setEditingNodeId(null)` を土台に、全選択・Esc キャンセル・空文字ガードを追加する。
- 全選択は「追加直後の自動編集時」のみ行う。通常クリック編集との区別のため、自動編集かどうかを示すフラグ（例: ローカル state や `editingNodeId` 一致の判定）を用いる。
- 修正後は、Tab / Enter 追加 → 全選択 → 置換 or Esc → 連続追加、の一連の流れを手動確認する。
