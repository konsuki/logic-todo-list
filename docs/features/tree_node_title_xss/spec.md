# Tree Node タイトル表示のXSSおよびレイアウト崩れ防止 仕様書

## 概要

`TreeView.jsx` において、各ノードのタイトルを表示する際に、入力された文字列が意図せずHTML要素としてパースされ描画・実行される脆弱性を排除する。

---

## 目的

- 悪意あるユーザー入力（`<script>` 等）によるクロスサイトスクリプティング（XSS）を防ぐ。
- ユーザー入力（`<h1>` や `<style>` 等）によるレイアウトの破壊を防ぐ。
- 全ての入力を「純粋なテキスト」として安全に描画する。

---

## 実装仕様

### `TreeView.jsx` の表示ロジック修正
- **対象箇所**: `src/components/features/tree/TreeView.jsx` のタイトルを挿入している処理部分
- **変更内容**: `d3` によるDOM挿入メソッドを、HTMLパーサーである `.html()` から、テキストエンコーダーである `.text()` に置き換える。
- **効果**: `<b>` や `<script>` などのタグが入力されても、単なる文字列（例: "&lt;b&gt;"）としてエスケープ表示され、実行やスタイル適用が行われない。
